## What it is

Independent artists, comics and promoters publish events. The public finds them and buys. One database sits under both sides: publishing makes an event public, and every sale updates the organizer's inventory live.

**The rule that never bends: no overselling, ever.**

## Surfaces

| Surface | For |
|---|---|
| Public site | Discovery, event pages, checkout (guest or signed in) |
| Attendee console | Tickets, transfers, guest lists |
| Organizer console | Events, ticket tiers, coupons, campaigns, payouts |
| Staff door | QR check-in on a phone, no account needed |
| Admin | Approvals, refunds, payouts, system health |

## Highlights

- Seat holds while checkout runs, committed inside a database transaction
- GST-correct pricing and receipts, money handled as integers
- Ticket PDF and email delivery, QR tickets, peer-to-peer transfers
- Recurring events and series
- Organizer identity verification (KYC) before payouts
- Dighead, an AI event-discovery assistant

## Stack
